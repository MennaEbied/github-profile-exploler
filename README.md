# GitHub Profile Explorer

A Next.js + TypeScript app to explore GitHub users and their repositories. Users can view profile details, browse repos, compare users, add notes, and more.

---

## 🚀 Features

- Search for a GitHub user by username  
- Display basic profile data: avatar, name, bio, repo count, followers, etc.  
- List repositories with info: name, description, star count  
- Compare two GitHub users side by side (repos, stars, followers)  
- Simple summary / analysis of a user’s activity  
- Notes feature: add notes for a user (stored locally)  
- Deployed to Vercel for easy sharing  

---

## 🧰 Tech Stack

- Next.js (React framework)  
- TypeScript  
- Tailwind CSS (for styling)  
- LocalStorage (for notes)  
- GitHub REST API
